# How to Temu (for cards)

A single-page guide to Temu's promo codes, gift calendars, cash-back offers, and other free-money mechanics, written for people buying trading cards.

## Disclaimer

Temu changes its promos constantly and this page will lag behind. Check the ⓘ on every offer before you spend anything. You might still get scammed.
